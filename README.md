The application allows users to create, view, edit, search, and delete notes through a clean and responsive interface.
A responsive note management application developed as part of the GoIT Fullstack course in collaboration with a team.

* Developed and styled UI components based on the Figma design.
* Implemented note-related functionality using React and TypeScript.
* Worked with REST API to fetch, create, update, and delete notes.
* Added search and pagination functionality for managing notes.
